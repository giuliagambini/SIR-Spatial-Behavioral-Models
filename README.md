# SIR Spatial Behavioral Models

![Language MATLAB](https://img.shields.io/badge/Language-MATLAB-orange.svg)

## Project Overview

This repository contains the code, theoretical study, and presentation for a reaction-diffusion SIR model exploring how human behavioral responses—specifically social and spatial distancing—can suppress Turing and Turing-Hopf spatio-temporal patterning in epidemics.

The code reproduces the numerical results presented in the paper:
> **d'Onofrio, A., Banerjee, M., & Manfredi, P. (2020).** *Spatial behavioural responses to the spread of an infectious disease can suppress Turing and Turing-Hopf patterning of the disease.* Physica A: Statistical Mechanics and its Applications, 545, 123773. [DOI: 10.1016/j.physa.2019.123773](https://doi.org/10.1016/j.physa.2019.123773)

The study investigates how populations actively adapt their habits in response to perceived epidemic threats, departing from the classical modeling approach that treats humans as passive actors and adding new behavioural terms.

## Repository Structure

* `/src` : MATLAB scripts for PDE numerical solutions, stability analysis, and plot generation.
* `/docs` : Project presentation slides and reference materials.

## Mathematical Model

The system models the dynamics of Susceptible ($S$) and Infectious ($I$) individuals by introducing a non-linear cross-diffusion term. This term mathematically represents *chemorepulsion* (spatial distancing), meaning individuals actively avoid geographic sites with a higher perceived risk, driven by the distancing strength parameter $A$:

$$\partial_t S = D_S \Delta S + \nabla \cdot (A S \nabla I) + \mu(1-S) - \Psi(S,I)$$
$$\partial_t I = D_I \Delta I + \Psi(S,I) - (\mu + \nu)I$$

The behavioral incidence rate is defined as $\Psi(S,I) = \phi(I)C(S,I)$, where $\phi(I)$ represents the reduction in social contacts as the local infection prevalence increases. Different forms of the various terms can be assumed.

## Key Findings Simulated

For the simulations, the so-called Sun model was used as a baseline, where initially $\phi(I)=1$, $C(S,I)=\beta S I^2$, and $\Psi(S,I)=\beta S I^2$ to establish a comparison scenario.    

* **Turing Instability:** Formation of spatial patterns when the diffusion of susceptible individuals is higher than that of infectious individuals ($D_S > D_I$ is a necessary condition, but not sufficient) and the numerical proof of the annihilation of the pattern.

The spatial behavioural response was then added to the Sun model through the flux $\psi = -D_S \nabla S - A S \nabla I$, leading to a non-linear cross-diffusion term. The following scenarios can be observed and proven:
* **Pattern Suppression:** When spatial distancing is super-critical ($A > A_{cr}$), it acts as an active, non-local stabilizer, completely annihilating complex pattern formation and restoring a homogeneous steady state.
* **Pattern Transitions:** For sub-critical values ($A < A_{cr}$), increasing the distancing parameter induces pattern transitions (e.g., from labyrinths to spots). Moreover, for certain values, insufficient spatial distancing allows the instability to grow, leading to the formation of high-prevalence epidemic clusters.

But what happens if the instability of the Endemic Equilibrium arises through a Hopf Bifurcation? We can obtain two symmetry-breaking scenarios:
* **Spatio-temporal Hopf instability:** Oscillations in time, but uniformity in space.
* **Turing-Hopf Instability:** Simultaneous breaking of both temporal and spatial symmetries. **Spatio-temporal chaos** can be observed, i.e., localized hotspots that pulse and evolve over time, creating unpredictable epidemic fluctuations.

It can be proven numerically that spatial distancing plays a key role in extinguishing unpredictable epidemic waves and controlling spatio-temporal chaos.

## How to Run the Code

1. Download this repository.
2. Open MATLAB and navigate to the extracted folder, setting the `/src` folder as your current working directory.
3. Open and run the main scripts to generate the spatial pattern simulations.
